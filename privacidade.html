CalParede

Política de privacidade

Atualizada em 25 de outubro de 2026

O CalParede é um programa para Windows de uso pessoal que mostra a agenda no papel de parede. Esta política explica quais dados ele trata, onde ficam guardados e com quem são compartilhados.

1. Não há servidor do CalParede

O CalParede não possui servidor próprio, não coleta estatísticas de uso e não envia dados a quem desenvolveu o programa. Todo o processamento acontece no computador do usuário.

2. Dados do Google Agenda

Quando o usuário conecta a conta do Google, o CalParede solicita duas permissões:

  • Ver agendas e eventos (calendar.readonly), para desenhar no papel de parede os compromissos das agendas que o usuário escolher;
  • Criar e excluir eventos (calendar.events), apenas para gravar no Google Agenda os compromissos que o próprio usuário adiciona pelo painel do CalParede e para apagá-los quando ele pede.

São usados apenas o título, a data, o horário, a cor e a agenda de cada evento. Esses dados não são vendidos, não são usados para publicidade, não são transferidos a terceiros e não são usados para treinar modelos de inteligência artificial.

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

3. O que fica guardado no computador

  • Na pasta %APPDATA%\CalParede: configurações, compromissos criados pelo painel, uma cópia temporária dos eventos para montar a imagem e o registro de funcionamento do programa.
  • A credencial do aplicativo e o acesso à conta do Google ficam no arquivo google.dat, protegidos pela proteção de dados do Windows (DPAPI), que só permite a leitura pelo mesmo usuário no mesmo computador.

4. Outros serviços

  • Clima: se o usuário ativar o clima, o programa consulta a Open-Meteo com as coordenadas da cidade configurada. Nenhum dado da agenda é enviado.
  • Agendas por link (.ics): se o usuário cadastrar links de outras agendas, o programa apenas baixa esses arquivos dos endereços informados.

5. Como apagar os dados

  • No painel do CalParede, em Ajustes, o botão Desconectar apaga o acesso salvo e revoga a permissão junto ao Google.
  • A permissão também pode ser removida a qualquer momento em myaccount.google.com/permissions.
  • Para apagar tudo, basta executar desinstalar.bat e excluir a pasta %APPDATA%\CalParede.
